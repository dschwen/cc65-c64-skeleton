Keyboard Shortcuts

Tab
Toggle active charset bank in Character and Tile modes when focus is not in a form control.
Ctrl/Cmd + C
Copy the selected character in character mode, or selected tile in tile mode.
Ctrl/Cmd + V
Paste into the selected character in character mode, or selected tile in tile mode.
1 2 3 4
In tile mode, assign the selected character to top-left, top-right, bottom-left, or bottom-right.
Left/right drag tile
In tile mode, edit pixels across the selected tile and its underlying characters.
Shift + click tile quadrant
Set that quadrant to the currently selected character.
Object grid click
Paint the selected bank 0 character, or set the hotspot when the hotspot tool is active.
Right mouse button
Clear pixels and object cells, or paint tile 0 on room/test canvases.
